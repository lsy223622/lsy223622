# lsy223622

Undergraduate student at **Xidian University**. I build practical software across systems, networking, desktop/mobile apps, and embedded hardware. Most of these started as tools I needed myself and decided to open source.

[Website](https://lsy223622.com) · [Blog](https://blog.lsy223622.com) · [All Repositories](https://github.com/lsy223622?tab=repositories)

## Systems, Audio & Networking

* [**HearPort**](https://github.com/lsy223622/HearPort) (`Swift`, `C++`, `WinUI 3`) — Turns an iPad into a low-latency speaker for a Windows 11 PC over Wi-Fi or USB. Supports automatic USB to Wi-Fi failover and PIN based pairing. · [Releases](https://www.google.com/search?q=https://github.com/lsy223622/HearPort/releases)

* [**UniDERP**](https://github.com/lsy223622/UniDERP) (`Go`, `Docker`) — Shares private Tailscale DERP relays across multiple independent tailnets with centralized access control, web management, and bandwidth scheduling per tailnet. · [Releases](https://www.google.com/search?q=https://github.com/lsy223622/UniDERP/releases)

* [**PinNode**](https://github.com/lsy223622/PinNode) (`Kotlin`, `Go`) — Turns an Android phone into a temporary Tailscale node with a 6-digit PIN, supporting centrally managed routing and automatic cleanup when the session ends. · [Releases](https://github.com/lsy223622/PinNode/releases)

* [**EveryTwins**](https://github.com/lsy223622/EveryTwins) (`C++`) — Fast, lightweight Windows duplicate file finder for whole disk scans, powered by Everything's local index to find duplicate files in seconds with minimal memory usage.

## Self-Hosted Web & Embedded

* [**BloGo**](https://github.com/lsy223622/BloGo) (`Go`, `JavaScript`) — Static blog engine compiled to a single binary with zero runtime dependencies, lightweight analytics, and a live preview dev mode. Powers [blog.lsy223622.com](https://blog.lsy223622.com). · [Releases](https://www.google.com/search?q=https://github.com/lsy223622/BloGo/releases)

* [**PathBay**](https://www.google.com/search?q=https://github.com/lsy223622/PathBay) (`Go`, `Docker`) — Lightweight HTTP route and response server with an embedded admin UI and JSON API for redirects, static pages, and files. · [Releases](https://www.google.com/search?q=https://github.com/lsy223622/PathBay/releases)

* [**NanoInk**](https://github.com/lsy223622/NanoInk) (`C`, `C++`, `ESP32`) — Compact ESP32 e-paper desktop terminal displaying daily class schedules, weather, time, battery status, and TOTP codes, running for over a month on a single charge.

## Desktop, Mobile & Daily Utilities

* [**XDUClassVideoDownloader**](https://github.com/lsy223622/XDUClassVideoDownloader) (`Python`, `Flask`) — Course video downloader for Xidian University's lecture capture platform, now with a local Flask WebUI, CLI, and automated batch mode. · [Releases](https://github.com/lsy223622/XDUClassVideoDownloader/releases)

* [**MotionPhotoManager**](https://github.com/lsy223622/MotionPhotoManager) (`Kotlin`, `Jetpack Compose`) — Android tool for batch splitting Motion Photos into JPEG stills and MP4 videos by parsing metadata locally. · [Releases](https://github.com/lsy223622/MotionPhotoManager/releases)

* [**DiaryAssistant**](https://www.google.com/search?q=https://github.com/lsy223622/DiaryAssistant) (`Python`) — Local Markdown diary companion using the DeepSeek API to maintain an evolving user profile, generate reflective comments, and compile weekly summaries.
